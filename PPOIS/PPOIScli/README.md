# Astronaut Training CLI

## Запуск

python main.py <command>

---

## COSMONAUT

cosmonaut add -n NAME -a AGE  
Создаёт космонавта

cosmonaut list  
Выводит список космонавтов

---

## TRAINING

training physical --id ID  
Проводит физическую тренировку

training equipment --id ID  
Тренировка работы с оборудованием

training zero --id ID  
Тренировка в невесомости

training simulator --id ID  
Тренировка в симуляторе

---

## MISSION

mission prepare --id ID  
Проверка готовности к миссии

---

## HELP

help  
Показать все команды

help cosmonaut  
help training  
help mission  

Показать команды раздела
